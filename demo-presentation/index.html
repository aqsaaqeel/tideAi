tideAI

idea → live app on DigitalOcean

A small “Lovable-style” builder for teams who want AI-generated React apps deployed without wiring GitHub, Docker, and App Platform by hand—on every try.

The problem

Shipping a front-end prototype usually means juggling codegen, a build, a container or static host, a registry, and an App Platform spec—before you even get a shareable URL.

tideAI compresses that into one guided flow from a single product idea.

What tideAI does

You enter a one-line product idea and a DigitalOcean API token. The service generates a full React + Vite project, builds it, pushes an image to DOCR, and creates an App Platform app—then returns a live URL.

By default it does not require GitHub.

How it works (pipeline)

1
Inference DigitalOcean Serverless Inference turns your idea into project files as JSON.
2
Parse & write Files land in a temp folder; npm install and npm run build run on the server.
3
Image Built dist/ is packaged with a tiny busybox httpd layer for serving.
4
Registry Image is pushed to DOCR via the Registry HTTP API (no local Docker daemon).
5
App Platform An app is created from that image; the UI polls until the live URL is ready.

Stack used in tideAI

  • UI: minimal React + Vite SPA talking to Express.
  • Backend: Node + Express orchestrates inference, build, DOCR, deploy.
  • Default model: llama3.3-70b-instruct (override with INFERENCE_MODEL).
Prerequisites for the happy path: DO token with Inference + Apps + Registry; Container Registry on the account; outbound HTTPS (e.g. busybox binary fetch unless customized).

Demo

  1. Open the tideAI UI (local Vite or deployed App Platform URL).
  2. Paste a crisp product one-liner (e.g. “A landing page for a waitlist with email capture”).
  3. Paste a DO personal access token with the right scopes.
  4. Submit and narrate progress: codegen → build → push → app create → URL.
  5. Open the child app URL and show it running in production.

Wrap-up

tideAI is a focused demo of “prompt to production” on DigitalOcean—good for founders, platform teams, and anyone selling DO App Platform + Inference + Registry together.
